Neat and Tidy! An Organization Game
This game was created by Melanie Sandoval, Silvana Velazquez, and Paris Sithavong.

Description
“Neat and Tidy!” is a mindless and easy-going game created to echo the cozy and
nostalgic gameplay of early 2000’s games. The storyline being that the user has moved
into a new home and must organize one more thing: a bookshelf. Upon starting the
game, the bookshelf will present an assortment of items that must be drag-and-dropped
by the player to the correct place.

Controls
The game functions on the user’s ability to click and hold the sprites to its assigned
spot.

Checklist
● Set positions for each sprite
● Sprite returns to randomized starting position if it is not in the correct position

Known Bugs
● Overlapping objects
● Dragging problem
● Setting random positions

Key Features
● Snap back function
● Sprite tracker for how many items are left
● Quirky hints throughout the stage for the user to find
● Satisfying snap noise and entertaining background music

How it was Built
● Built in Snap!, built with basic and customized blocks
● Set coordinates to each item position
● Used “touching?”, “if else”, “repeat until”, and “forever” blocks to have the game working
● Set random positions to start the game

How to Play
● Click the green flag
● Click “Play” button
● Drag and drop each items in the right position
● (Click the dinosaur for hints)
● When everything is sorted on the bookshelf, the player wins
